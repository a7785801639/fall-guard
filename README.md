# FallGuard — Система видеоконтроля и защиты от падений

Локальная система компьютерного зрения на базе `YOLO11-pose` (`TensorRT FP16` / `CUDA` / `ONNX Runtime`) + `ByteTrack` + `2.5D` гомографии пола + биометрии лиц `OpenCV SFace` для круглосуточного домашнего присмотра за пожилым человеком после инсульта.

## Архитектура и возможности

- **Контроль состояния и упреждение падений:**
  1. **Жест вызова помощи (`help_call`):** удержание поднятой руки над плечом и головой (`3.2 с`) отправляет уведомление со снимком в Telegram.
  2. **Самостоятельный подъём (`sitting_up`, `left_bed`):** посадка в кровати со свешиванием ног за край матраса или выход из зоны кровати без сопровождения.
  3. **Падение (`fallen`):** обнаружение осевшего или горизонтального положения на полу вне матраса (включая сползание с кровати или прикроватного стула) с циклом повторных оповещений каждые `15 с` до подтверждения.
- **Отделение пациента от родственников и предметов:**
  - **Защёлка кровати и режим визита:** фиксация спящего пациента в контуре матраса (в том числе под одеялом и в ночном ИК-режиме); при входе родственника через зону двери или нахождении рядом упреждающие тревоги подъёма подавляются, а если родственник оставил человека спокойно сидеть и вышел — сохраняется спокойный режим с непрерывным контролем падения.
  - **Биометрия лиц (`YuNet` + `SFace ONNX`) и самообучение:** локальная галерея лиц пациента и близких с автоматическим пополнением эталонов «Своих» при нажатии кнопки `❌ Ты ошибся` (с защитой от ракурсов со спины и зоны кровати).
  - **Фильтр неподвижных объектов (`StaticObjectGate`) и `2.5D` гомография пола (`FloorHomography`):** отсечение неподвижных предметов интерьера и перевод координат опоры в сантиметры относительно борта матраса.
- **Прямой видеопоток `H.264 fMP4` и веб-интерфейс / Telegram Mini App:**
  - Трансляция живого потока камеры через `WS /ws/stream` (`MSE` fragmented MP4 `-c:v copy` без перекодирования видео) с синхронной клиентской отрисовкой телеметрии по `WS /ws/telemetry` (`12 Гц`) и резервным `MJPEG`.
  - Прямой бесшовный доступ в локальной сети и криптографическая защита внешнего входа через **Telegram Mini App** (`HMAC-SHA256` проверка `Telegram.WebApp.initData` по белому списку подписчиков бота).
- **Двухфазные уведомления в Telegram:**
  - Мгновенная отправка кадра тревоги с двумя кнопками (`✅ Я рядом` и `❌ Ты ошибся`), после чего через `4 с` фото в том же сообщении автоматически заменяется готовым `9`-секундным видеоклипом `MP4` (`5 с до + 4 с после`) через `editMessageMedia`.
  - Постоянное нижнее меню управления личной подпиской, запроса свежего кадра, статуса и кнопка запуска видеопульта **Mini App** (`/app`).

## Запуск

1. Скопируйте `.env.example` в `.env` и заполните `RTSP_URL`, `TG_BOT_TOKEN`, `TG_BOT_USERNAME` и (при публикации Mini App за обратным прокси) `PUBLIC_WEBAPP_URL`.
2. **Docker (CPU AVX2):**
   ```bash
   docker compose up -d --build fall-guard
   ```
3. **Docker (NVIDIA GPU / CUDA / TensorRT):**
   ```bash
   docker compose --profile gpu up -d --build fall-guard-gpu
   ```
4. **Проверка тестов:**
   ```bash
   pytest tests -q
   ```
