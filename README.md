# FallGuard — Система видеоконтроля и защиты от падений

Локальная система компьютерного зрения на базе `YOLO11-pose` (`TensorRT FP16` / `CUDA` / `ONNX Runtime`) + `ByteTrack` + `2.5D` гомографии пола + биометрии лиц `OpenCV SFace` для круглосуточного домашнего присмотра за пожилым человеком после инсульта.

## Архитектура и возможности

- **Контроль состояния и упреждение падений:**
  1. **Жест вызова помощи (`help_call`):** удержание поднятой руки над плечом и головой (`3.2 с`) отправляет уведомление со снимком в Telegram.
  2. **Самостоятельный подъём (`sitting_up`, `left_bed`):** посадка в кровати со свешиванием ног за край матраса или выход из зоны кровати без сопровождения.
  3. **Падение (`fallen`):** обнаружение осевшего или горизонтального положения на полу вне матраса (включая сползание с кровати или прикроватного стула) с циклом повторных оповещений каждые `15 с` до подтверждения.
- **Отделение пациента от родственников и предметов:**
  - **Защёлка кровати и режим визита:** фиксация спящего пациента в контуре матраса (в том числе под одеялом и в ночном ИК-режиме); при входе родственника через зону двери или нахождении рядом упреждающие тревоги подъёма подавляются, а если родственник оставил человека спокойно сидеть и вышел — сохраняется спокойный режим с непрерывным контролем падения.
  - **Биометрия лиц (`YuNet` + `SFace ONNX`) и самообучение:** локальная галерея лиц пациента и близких с автоматическим пополнением эталонов «Своих» при нажатии кнопки `❌ Ты ошибся` (с защитой от ракурсов со спины и зоны кровати).
  - **Фильтр неподвижных объектов (`StaticObjectGate`) и `2.5D` гомография пола (`FloorHomography`):** отсечение неподвижных предметов интерьера и перевод координат опоры в сантиметры относительно борта матраса.
- **Прямой видеопоток `H.264 fMP4` и веб-интерфейс / Telegram Mini App:**
  - Трансляция живого потока камеры через `WS /ws/stream` (`MSE` fragmented MP4 `-c:v copy` без перекодирования видео) с синхронной клиентской отрисовкой телеметрии по `WS /ws/telemetry` (`12 Гц`) и резервным `MJPEG`.
  - Прямой бесшовный доступ в локальной сети и криптографическая защита внешнего входа через **Telegram Mini App** (`HMAC-SHA256` проверка `Telegram.WebApp.initData` по белому списку подписчиков бота).
- **Двухфазные уведомления в Telegram:**
  - Мгновенная отправка кадра тревоги с двумя кнопками (`✅ Я рядом` и `❌ Ты ошибся`), после чего через `4 с` фото в том же сообщении автоматически заменяется готовым `9`-секундным видеоклипом `MP4` (`5 с до + 4 с после`) через `editMessageMedia`.
  - Постоянное нижнее меню управления личной подпиской, запроса свежего кадра, статуса и кнопка запуска видеопульта **Mini App** (`/app`).

- **Страховка тревоги падения от путаницы ролей:**
  - Если визит родственника только «защёлкнут» по двери, а в кадре уже 30 с никого, кроме пациента, нет — падение / сползание больше не подавляется.
  - «Человек на полу»: любой (гость, неопознанный) человек, неподвижно лежащий на полу 6+ с без стоящего рядом помощника, вызывает тревогу падения независимо от присвоенной роли (отключается в настройках).
  - Перепроверка ролей по лицу раз в 2 с: смена «бабушка ⇄ свой» только по двум подряд уверенным совпадениям.
- **Режим «Только падение и сползание» у каждого получателя:** кнопка на главном экране пульта, кнопка `🚨 Только падения` / команды `/fallsonly`, `/allevents` в боте, переключатель у каждого чата и телефона во вкладке «Кому сигналить». В этом режиме посадка, выход из кровати, жест рукой и «нет в кадре» только пишутся в хронику.
- **Android-приложение (`android/`):** пульт во встроенном браузере + фоновый сервис. При падении — сирена на канале будильника (звучит в беззвучном режиме) и окно поверх экрана блокировки с кадром и кнопками «Я рядом» / «Ложная тревога». Работает без Firebase: держит long-poll `GET /api/alerts/poll` к вашему серверу (дома по LAN, вне дома по `PUBLIC_WEBAPP_URL`).

## Запуск

1. Скопируйте `.env.example` в `.env` и заполните `RTSP_URL`, `TG_BOT_TOKEN`, `TG_BOT_USERNAME` и (при публикации Mini App за обратным прокси) `PUBLIC_WEBAPP_URL`.
2. **Docker (CPU AVX2):**
   ```bash
   docker compose up -d --build fall-guard
   ```
3. **Docker (NVIDIA GPU / CUDA / TensorRT):**
   ```bash
   docker compose --profile gpu up -d --build fall-guard-gpu
   ```
4. **Проверка тестов:**
   ```bash
   pytest tests -q
   ```

## Android-приложение

**Установка.** Готовый APK собирает GitHub Actions (workflow «Android APK», артефакт `fallguard-apk`). Тег `android-v1.2` публикует APK в GitHub Releases. Локально:

```bash
cd android && ./gradlew assembleRelease
```

Нужны JDK 17 и Android SDK 35. Телефон — Android 8.1+.

**Постоянный ключ подписи.** Без него каждая сборка из CI подписана новым отладочным ключом, и обновление ставится только после удаления старой версии. Один раз создайте ключ и сохраните в секретах репозитория `FG_KEYSTORE_BASE64`, `FG_KEYSTORE_PASSWORD`, `FG_KEY_ALIAS` (ключ храните отдельно — без него обновить приложение поверх не получится):

```bash
keytool -genkeypair -v -keystore fallguard.jks -alias fallguard -keyalg RSA -keysize 2048 -validity 10000
```

```bash
base64 -w0 fallguard.jks
```

**Привязка.** В пульте: «Настройки → Кому сигналить → Подключить телефон», навести камеру телефона на QR-код (или ввести адрес сервера и 8-значный код). Сразу после привязки приложение покажет, каких разрешений не хватает (уведомления, работа в фоне, окно поверх блокировки), и даст проверить сирену.

**Как работает.** Пульт открывается внутри приложения; фоновый сервис держит связь с сервером (дома по LAN, вне дома по `PUBLIC_WEBAPP_URL`) без Firebase. При падении — своя двухтональная сирена на канале будильника (звучит и в беззвучном режиме) и окно поверх экрана блокировки с кадром и кнопками «Принято, иду» / «Ложная тревога». Когда к бабушке подходит свой, тревога снимается сама, телефон замолкает и показывает «Рядом свой — тревога снята». Кнопка «Экран» в пульте не даёт экрану гаснуть — удобно держать старый телефон или планшет у кровати как монитор.

Телефон авторизуется постоянным токеном устройства (на сервере хранится только SHA-256 в `data/devices.json`), отвязать его можно в пульте или в приложении. Для доступа вне дома Nginx должен проксировать WebSocket (`/ws/*`), передавать `X-Forwarded-For` и не обрывать запросы короче 60 с (`proxy_read_timeout 75s`). Если прокси стоит не на 192.168.1.6, укажите его адрес в `REVERSE_PROXY_IPS`.
